# 🍔 منوی دیجیتال فست‌فود (بدون بک‌اند)

یک منوی دیجیتال حرفه‌ای، سریع و کاملاً سمت‌کاربر (Client-Side) که تنها با استفاده از HTML, CSS, JavaScript و JSON ساخته شده است. این پروژه نیازی به دیتابیس و سرور ندارد و مستقیماً روی **GitHub Pages** قابل انتشار است.

## 🚀 ویژگی‌ها
- 🌙 طراحی مدرن و Mobile-First با تم تیره.
- ⚡️ مدیریت داده‌ها از طریق فایل `menu.json` (بدون نیاز به کدنویسی برای تغییر آیتم‌ها).
- 🔍 جستجوی زنده (Live Search) و فیلتر دسته‌بندی‌ها.
- 📱 دکمه‌های شناور برای تماس، مسیریابی و اینستاگرام.
- 🖼️ مدیریت خطای لود نشدن عکس‌ها (نمایش عکس جایگزین).

## 🛠️ نحوه اجرا روی سیستم خودتان (Local)
از آنجا که از `fetch()` برای خواندن فایل JSON استفاده شده است، نمی‌توانید فایل `index.html` را مستقیماً با مرورگر باز کنید (ارور CORS).
باید از یک Local Server استفاده کنید:
1. در VS Code افزونه **Live Server** را نصب کنید.
2. روی فایل `index.html` راست‌کلیک کرده و `Open with Live Server` را بزنید.

## ✏️ نحوه ویرایش و شخصی‌سازی
تمامی اطلاعات منو در فایل `menu.json` قرار دارد. ساختار هر آیتم به شکل زیر است:
```json
{
  "id": 1,
  "name": "نام غذا",
  "category": "شناسه دسته‌بندی (pizza, burger, drink, ...)",
  "description": "مواد تشکیل دهنده",
  "price": 150000,
  "image": "لینک یا آدرس عکس",
  "available": true,
  "badges": ["تند", "پرفروش"]
}
- **تغییر قیمت/عکس/توضیح**: فقط کافیست مقادیر فایل `menu.json` را تغییر دهید.
- **ناموجود کردن یک آیتم**: مقدار `"available": true` را به `false` تغییر دهید.
- **تغییر شماره تماس و لینک‌ها**: در فایل `index.html` انتهای کد، به دنبال تگ‌های `<a>` داخل کلاس `.fab-container` بگردید و لینک‌های `href` را اصلاح کنید.

## 🌐 نحوه انتشار رایگان در GitHub Pages
1. یک ریپازیتوری (Repository) جدید در گیت‌هاب بسازید.
2. این ۴ فایل (`index.html`, `style.css`, `script.js`, `menu.json`) را در آن آپلود کنید.
3. در ریپازیتوری خود به تب **Settings** بروید.
4. از منوی سمت چپ بخش **Pages** را انتخاب کنید.
5. در بخش *Build and deployment*، گزینه *Source* را روی **Deploy from a branch** بگذارید.
6. در بخش *Branch*، شاخه **main** (یا master) را انتخاب کرده و روی **Save** کلیک کنید.
7. چند دقیقه صبر کنید. لینک سایت شما (مثلاً `https://yourusername.github.io/your-repo`) ساخته می‌شود.

## 📱 ساخت QR Code
لینک سایتی که در مرحله قبل از GitHub دریافت کردید را کپی کنید. وارد یک سایت ساخت کیوآرکد رایگان (مثل [qr-code-generator.com](https://www.qr-code-generator.com/)) شوید، لینک را Paste کنید و عکس QR Code را دانلود کنید تا روی میزهای رستوران قرار دهید.

### توضیحات تکمیلی پیرامون معماری و Trade-off ها (طبق Custom Instructions شما):

**چرا این معماری (Vanilla JS + JSON) انتخاب شد؟**
- **مزایا**: سرعت بی‌نظیر (به دلیل نبود درخواست‌های متعدد به بک‌اند)، هزینه صفر (هاستینگ رایگان گیت‌هاب)، امنیت بالا (هیچ دیتابیس حساس و لاگینی وجود ندارد) و عدم نیاز به یادگیری فریم‌ورک‌های سنگین (React/Vue) برای یک پروژه ساده.
- **معایب**: آپدیت کردن منو نیازمند دسترسی به فایل JSON و Push کردن در گیت‌هاب است (نمی‌توانید پنل ادمین موبایلی به صاحب رستوران بدهید تا خودش با یک کلیک آپدیت کند).
- **Trade-off**: برای یک رستوران کوچک که منوی ثابتی دارد، این روش بسیار ارزان‌تر و پایدارتر از خرید هاست، دیتابیس و طراحی پنل ادمین با PHP یا Node.js است.

**ساختار ماژولار و CSS Variables**:
رنگ‌بندی، فواصل و فونت‌ها در `root:` فایل CSS تعریف شده‌اند. اگر روزی خواستید تم قرمز/نارنجی را به سبز (مثلاً برای رستوران گیاهی) تغییر دهید، فقط کافیست متغیر `--primary-color` را عوض کنید و کل سایت آپدیت می‌شود.

**مدیریت خطا (Error Handling)**:
در JS از ویژگی `onerror` در تگ‌های تصویر استفاده کردم. اگر لینک عکسی در JSON خراب باشد، سایت به هم نمی‌ریزد، بلکه تابع `handleImageError` یک Placeholder زیبا و هماهنگ با تم تیره لود می‌کند.
