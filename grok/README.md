# منوی دیجیتال کاکتوس فست‌فود

**تم تیره، مدرن و اشتها‌برانگیز** • **راست‌چین** • **Mobile First** • **Vanilla JS + JSON**

---

## نحوه اجرای پروژه

1. تمام فایل‌ها را در یک پوشه جدید قرار دهید.
2. فایل `index.html` را با مرورگر (فایرفاکس/کروم) باز کنید.
3. منو از طریق `menu.json` خوانده می‌شود.
4. کارت‌ها به صورت خودکار از داده‌های JSON بارگذاری می‌شوند.

## نحوه ساخت QR Code (برای انتشار)

1. فایل `index.html` را در پوشه‌ای که در `GitHub Pages` آپلود می‌کنید قرار دهید.
2. از این سایت استفاده کنید:  
   **https://www.qr-code-generator.com**
3. متن زیر را در گزینه "Link" paste کنید:  
   `https://yourusername.github.io/your-repo-name/`
4. گزینه "QR Code Size" را ۵۰۰×۵۰۰ پیکسل بگذارید.
5. دکمه Generate را بزنید و فایل PNG را دانلود کنید.
6. فایل `QR.png` را در پوشه اصلی پروژه بذارید.

## شخصی‌سازی منو (بسیار ساده)

**فقط فایل `menu.json` را ویرایش کنید:**

- `name`: نام غذا
- `description`: توضیح کوتاه
- `price`: قیمت به تومان
- `image`: لینک عکس (picsum.photos)
- `category`: یکی از دسته‌بندی‌های زیر
- `tags`: آرایه تگ‌ها (مثلاً `["گوشت", "تازه"]`)
- `available`: `true` یا `false` (برای نمایش وضعیت موجود/ناموجود)

**دسته‌بندی‌های مجاز:**
- پیتزا
- برگر
- ساندویچ
- سوخاری
- پیش‌غذا
- نوشیدنی
- سس و افزودنی

## تغییرات تم (CSS Variables)

تمام رنگ‌ها و استایل‌ها با متغیرهای CSS تعریف شده‌اند. برای تغییر تم کافیست خطوط زیر را ویرایش کنید:
```css
:root {
--primary: #ff6b35;     /* رنگ اصلی */
--dark: #121212;        /* پس‌زمینه */
--card: #1f1f1f;       /* رنگ کارت‌ها */
}
