# 🍔 منوی دیجیتال فست‌فود فارسی

یک منوی آنلاین کاملاً واکنش‌گرا برای فست‌فودها که مشتریان می‌توانند با اسکن یک QR Code آن را در موبایل خود باز کنند. بدون نیاز به بک‌اند یا دیتابیس – فقط HTML/CSS/JS خالص.

## ✨ ویژگی‌ها

- تمام محتوا از یک فایل `menu.json` خوانده می‌شود.
- تم تیره، مدرن و اشتهابرانگیز با زبان فارسی و راست‌چین.
- جستجوی زنده و فیلتر بر اساس دسته‌بندی‌ها.
- نمایش تعداد نتایج و برچسب‌های «موجود» / «ناموجود».
- مدیریت خطای تصاویر با جایگذاری یک placeholder.
- دکمه‌های تماس، مسیریابی (گوگل مپ)، اینستاگرام و بازگشت به بالا.
- لوگو و نام برند در هدر.
- کاملاً Mobile First و بدون فریم‌ورک.
- SEO اولیه با متاتگ‌های مناسب.
- کد تمیز، کامنت‌دار و ماژولار.

## 🚀 اجرای محلی (توسعه یا نمایش)

۱. این ریپازیتوری را دانلود یا کلون کنید.  
۲. مطمئن شوید فایل‌ها در کنار هم قرار دارند:
   - `index.html`
   - `style.css`
   - `script.js`
   - `menu.json`
   - یک پوشه `images` که تصاویر غذاها درون آن قرار می‌گیرند (مسیرها در `menu.json` تعریف شده‌اند).  
۳. فایل `index.html` را با یک مرورگر باز کنید (توصیه: از یک سرور محلی مثل Live Server استفاده کنید تا خطای CORS برای fetch پیش نیاید، اما در بسیاری از مرورگرها fetch فایل محلی کار می‌کند).

> ⚠️ اگر به دلیل سیاست CORS فایل `menu.json` لود نشد، از افزونه [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) در VS Code استفاده کنید یا پروژه را روی GitHub Pages منتشر کنید.

## 📦 انتشار روی GitHub Pages

۱. یک مخزن جدید در گیت‌هاب ایجاد کنید.  
۲. فایل‌های زیر را در شاخه اصلی (main) مخزن آپلود کنید:
   - `index.html`
   - `style.css`
   - `script.js`
   - `menu.json`
   - پوشه `images` با تمام عکس‌ها.  
۳. به تنظیمات مخزن بروید -> بخش `Pages` -> در قسمت Source، شاخه `main` را انتخاب کنید و روی Save کلیک کنید.  
۴. پس از چند دقیقه، آدرس عمومی شما آماده خواهد شد (مانند `https://username.github.io/repo-name/`).  
۵. این همان آدرسی است که مشتری با اسکن QR Code می‌بیند.

## 🔲 ساخت QR Code

- از ابزارهای رایگان مانند [QR Code Generator](https://www.qr-code-generator.com/) یا [qrcode-monkey](https://www.qrcode-monkey.com/) استفاده کنید.
- آدرس عمومی پروژه خود را (همان لینک GitHub Pages) وارد کنید.
- کد QR را دانلود کرده و روی میزها، کارت‌ها یا منوی فیزیکی چاپ کنید.

## 🛠 شخصی‌سازی

### تغییر محتوای منو
فایل `menu.json` را ویرایش کنید. برای هر آیتم فیلدهای زیر وجود دارند:

| فیلد | توضیح |
|------|-------|
| `id` | شناسه یکتا |
| `name` | نام غذا |
| `price` | قیمت به تومان |
| `description` | توضیح کوتاه (اختیاری) |
| `image` | مسیر عکس (نسبت به فایل index.html) |
| `category` | دسته‌بندی: پیتزا، برگر و ... |
| `badges` | آرایه‌ای از برچسب‌ها مانند ["تند", "محبوب"] |
| `available` | `true` = موجود، `false` = ناموجود |

### تغییر لینک‌های تماس/مسیریابی/اینستاگرام
در فایل `index.html`، بخش `<footer>` لینک‌ها را مطابق نیاز خود ویرایش کنید:
```html
<a href="tel:شماره_تلفن_شما">تماس</a>
<a href="آدرس_گوگل_مپ">مسیریابی</a>
<a href="لینک_اینستاگرام">اینستاگرام</a>

### تغییر رنگ‌ها و استایل
تمامی رنگ‌ها در بخش `:root` فایل `style.css` به صورت متغیر تعریف شده‌اند. می‌توانید مقادیر آنها را تغییر دهید تا با برند شما هماهنگ شود.

### تعویض لوگو
در بخش هدر `index.html`، تگ `<img class="logo">` را با لوگوی خود جایگزین کنید.

## 📖 توضیح و راهنمای شخصی‌سازی

### 1️⃣ اجرا روی سیستم خودتان
کافی است پوشه پروژه را باز کرده و روی فایل `index.html` دوبار کلیک کنید. در مرورگر، منو را به صورت کامل می‌بینید.  
اگر فایل `menu.json` به دلیل محدودیت CORS لود نشد (مثلاً هنگام باز کردن مستقیم فایل HTML)، **از یک سرور محلی استفاده کنید**. ساده‌ترین راه:  
- در VS Code افزونه **Live Server** را نصب کنید، روی `index.html` راست‌کلیک و `Open with Live Server` را بزنید.

### 2️⃣ مدیریت منو با `menu.json`
تنها کاری که باید انجام دهید، ویرایش این فایل است.  
- **افزودن آیتم جدید**: یک شیء جدید با همان ساختار اضافه کنید.  
- **تغییر قیمت**، **موجودی**، یا **تصویر**: فیلدهای متناظر را ویرایش کنید.  
- **دسته‌بندی‌ها** به‌طور خودکار از همین فایل استخراج می‌شوند (نیازی به تغییر HTML یا JS نیست).  
- اگر آیتم‌های زیادی دارید نیازی به تغییر کد نیست، همه چیز پویا کار می‌کند.

### 3️⃣ سفارشی‌سازی ظاهر
- **تغییر تم رنگی**: در فایل `style.css` به بخش `:root` بروید. مقدار `--accent` را به رنگ برند خود (مثلاً قرمز: `#e63946`) تغییر دهید. بقیه متغیرها نیز قابل تنظیم هستند (پس‌زمینه، متن و...).  
- **قلم**: پروژه از فونت [Vazirmatn](https://github.com/rastikerdar/vazirmatn) استفاده می‌کند. اگر می‌خواهید فونت دیگری داشته باشید، لینک فونت در `<head>` یا تعریف `--font-family` را عوض کنید.

### 4️⃣ انتشار روی GitHub Pages
۱. یک مخزن public در GitHub بسازید.  
۲. تمام فایل‌ها (همراه پوشه `images` با عکس‌ها) را آپلود کنید.  
۳. به `Settings` > `Pages` بروید، `Source` را روی `main` بگذارید و ذخیره کنید.  
۴. پس از چند ثانیه لینک صفحه آماده می‌شود.  
۵. لینک نهایی را در یک QR Code Generator رایگان قرار دهید تا یک کد QR دریافت کنید. این کد را می‌توانید پرینت کنید و روی میز مشتریان بگذارید.

### 5️⃣ نکته‌های امنیتی و بهینه‌سازی
- این پروژه **هیچ اطلاعاتی به سرور ارسال نمی‌کند** و کاملاً سمت کاربر اجرا می‌شود.  
- تصاویر با `loading="lazy"` بارگذاری می‌شوند تا سرعت بالا باشد.  
- جستجو و فیلترها روی داده‌های داخل صفحه انجام می‌شوند و نیازی به درخواست جدید نیست.
